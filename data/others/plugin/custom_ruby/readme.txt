このプラグインを導入することで、[ruby]タグを表示させた際に
テキストが下方向へスライドしてしまう現象を抑制できます。

また、ルビのフォントサイズやルビの表示位置などの調整や変更が可能になります。
ティラノスクリプト、ティラノビルダーのV4、V5であれば対応しています。


■注意

カスタムルビプラグイン V1.xx以前とパラメータに互換性がありませんので
差し替えで使用する場合は注意してください。


■導入方法

１．
このテキストと同じフォルダにある「custom_ruby」フォルダを
使用するプロジェクトフォルダの「data/others/custom_ruby」
にコピーしてください。
(「data/others/plugin/custom_ruby/init.ks」　となるように配置してください。)

２．
first.ks、またはその直後に読み込むksファイル
（ビルダーの場合は[data/scenario/system/plugin.ks]の1行目を推奨）などの
ゲーム起動時に必ず通過するシナリオファイルで

[plugin name=custom_ruby]

を記述します。

基本的にはこれだけで既存の[ruby]タグ使用時に下へスライドしたり
ルビの文字数が多い時に左右に空白ができる現象はなくなります。
ただし、自動で行間を広げることもなくなるので、
必要に応じてConfig.tjsのdefaultLineSpacingを調整したり、
プラグイン読み込み時のパラメータでフォントサイズや表示位置を調整してください。


設定できるパラメータは下記のとおり設定可能です。

    scale      [省略可] フォントサイズを倍率で指定します。（例：0.5指定で元のフォントの50％）0.33などの小数点2桁以下でも指定可能です。 (初期値：0.5)
    x          [省略可] x方向をpx単位で指定します。数字が増えるほど右方向にルビが表示されます。マイナス指定可。 （初期値：0）
    y          [省略可] y方向をpx単位で指定します。数字が増えるほど下方向にルビが表示されます。マイナス指定可。 （初期値：0）
    spacing    [省略可] 字間を指定できます。数字が増えるほど文字と文字の間隔が開きます。マイナス指定可。指定しない場合は、デフォルトの字間になります。
    color      [省略可] 文字色を 0xRRGGBB 形式で指定できます。CSSﾁｮｯﾄﾜｶﾙ場合は"rgba(0, 0, 0, .5)"なども指定も可能です。指定しない場合はルビを振る文字と同じ色になります。
    background [省略可] 背景色を 0xRRGGBB 形式で指定できます。CSSﾁｮｯﾄﾜｶﾙ場合は"rgba(0, 0, 0, .5)"なども指定も可能です。指定しない場合は透明です。
    bold       [省略可] 太字にする場合はtrueを指定します。太字にフォントが対応していない場合は効果がありません。ルビ元のテキストが太字の場合自動的に太字になります。falseを指定するとルビ元が太字でも標準になります。
    italic     [省略可] 斜体にする場合はtrueを指定します。斜体にフォントが対応していない場合は効果がありません。ルビ元のテキストが斜体の場合自動的に斜体になります。falseを指定するとルビ元が斜体でも標準になります。
    face       [省略可] フォントの種類を指定できます。ティラノスクリプトの仕様上、半角スペースを含むフォント名を受け渡すには変数を経由する必要があります。指定しない場合はルビを振る文字と同じフォントになります。
    reverse    [省略可] ルビの位置を横書きの場合は下に、縦書きの場合は左に変更する場合はtrueを指定します。 （初期値：false）

例：
[plugin name=custom_ruby scale=0.33 y=-2]
→ルビのサイズを本文の33%の大きさで、基準より2px上に表示


■rubyタグ使用時

rubyタグ使用時にも個別でパラメータの指定が可能となります。

この[ruby text="る"]ル[ruby text="び"]ビはプラグイン記述時の設定。[r]
こっちの[ruby text="る" scale=0.8]ル[ruby text="び" scale=0.8]ビより[r]
こっちの[ruby text="る" scale=0.4]ル[ruby text="び" scale=0.4]ビの方が小さい。[p]


工夫をすれば[ruby text="・"]傍[ruby text="・"]点や、[ruby text="￣" scale=1 y=2 reverse=true]下[ruby text="￣" scale=1 y=2 reverse=true]線を引くことも出来る。[p]
